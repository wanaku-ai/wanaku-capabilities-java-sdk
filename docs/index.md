# Wanaku Capabilities Java SDK

The Wanaku Capabilities Java SDK is a set of plain-Java libraries for components that work with [Wanaku](https://wanaku.ai). Wanaku Barn and the Camel Integration Capability use it. It contains the shared API types, a client for the Wanaku services API, OAuth2 client-credentials helpers, a Camel runtime, a Maven artifact downloader, and a BOM (Bill of Materials) that aligns the versions.

> [!NOTE]
> This documentation covers the `main` branch. Version 0.3.0 removed the gRPC, discovery, data-file, and configuration-provider modules. For the 0.2.x line, see the [Wanaku Capabilities Java SDK 0.2.x documentation](https://github.com/wanaku-ai/wanaku-capabilities-java-sdk/tree/0.2.x/docs).
