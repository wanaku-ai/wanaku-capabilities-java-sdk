# Wanaku Capabilities Java SDK

This project is the set of plain-Java libraries that the Java components of [Wanaku](https://wanaku.ai) share: Wanaku Barn, the Camel Integration Capability, and the Wanaku Semantic Router.

For more information about the main Wanaku project, please visit the [Wanaku GitHub repository](https://github.com/wanaku-ai/wanaku).

## Documentation

The documentation is published at [wanaku.ai/docs/java-sdk/next](https://wanaku.ai/docs/java-sdk/next/). Its source is the [docs](docs/index.md) folder.

- [Get started](https://wanaku.ai/docs/java-sdk/next/get-started/) - Add the SDK to a Maven project
- [Guides](https://wanaku.ai/docs/java-sdk/next/guides/) - Call the Wanaku services API, load service catalogs and routes, download Maven artifacts
- [Reference](https://wanaku.ai/docs/java-sdk/next/reference/) - The published modules and the API types
- [Contributing](https://wanaku.ai/docs/java-sdk/next/contributing/) - Build, test, document, and release the SDK
